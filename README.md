# Mikrodalgadaki Dunku Corbanin Referandumu

> **Resmi uyari:** Bu yazilim evrendeki en onemli soruyu cevaplar: *Dunku corba isinmak istiyor mu, yoksa sadece sessizce bekliyor mu?*

Bilim insanlari yillarca mikrodalga icindeki buhari "sadece fizik" sanmistir. Yanlis. Buhar oy kullanir. Doner tabla sandik gorevlisidir. Kapak lastigi bagimsiz gozlemcidir. Siz sadece vatandassiniz.

## Bu proje ne yapar?

1. Corbanin adini alir.
2. Buzdolabinda kac gundur rehin tutuldigunu sorar.
3. Kapak kapaliligini denetler (acik kapak = secim hilesi).
4. 17 + (gun x 3) oyluk ciddi bir millet meclisi toplar.
5. Kazanani ilan eder. Uygulama emri basar. Bip sesi bekler.

Hicbir gercek aclik sorununu cozmez. Buna ragmen calisir.

## Kurulum

Python 3.10+ yeter. Baska bir sey istemez. Mikrodalga bile istemez; o zaten evde duruyor.

```bash
python3 referandum.py --corba "ezogelin" --gun 2
```

Kapagi acik birakirsaniz sistem sizi ihbar eder:

```bash
python3 referandum.py --corba "yayla" --gun 1 --kapak-acik
```

Bes gunden eski corba referanduma giremez. O bir kazidir.

## Siyasi durus

Bu repo tarafsizdir. Corba tarafsizdir. Mikrodalga tarafsiz degildir; o sicaktan yanadir. Daha fazla yorum yok. Gercekten yok. `--sifre` diye bir bayrak da yok. Varsa bile bakmayin.

## Sikca sorulan sorular

**Neden 17 oy?** Cunku 16 az, 18 cok. 17 bilimseldir.

**Copilot bu kodu anlar mi?** Anlar ama onaylamaz. Ona sorun, "corba oy kullanamaz" diyecektir. Kullanir.

**Patates var mi?** Yok. Yasak. Genelge 4.

**Bu bir bakanlik projesi mi?** Degil. Daha kotu: gönüllü.
